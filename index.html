Defensive Playbook Lab Help

Quick reference, storage guidance, and release information.

1. Choose a real play

  1. Select a formation family and formation.
  2. Filter by play type or map status.
  3. Select the actual play from the list.

2. Edit assignments

  1. Click a defender on the field or right menu.
  2. Choose a role-valid visual responsibility.
  3. Manual overrides appear with solid gold play-art lines.

3. Map the play

Unmapped uses an inferred shell. Save a Draft while working. Mark it Verified only after comparing it with the in-game play art.

4. Save a macro

A macro slot stores the formation, actual play, passing strength, and complete assignment package. The ten slots match the active defensive adjustment limit documented by EA.

5. Navigate team playbooks

Search all 138 teams, pin favorites, reopen recent teams, or browse every team using the same defensive scheme.

6. Scout the opponent

Record personnel and tendencies, select a base offensive concept, then view its route or run art against a saved defensive macro without changing the macro slot.

7. Build the tendency board

Save situation, personnel, offensive set, and concept tendencies, then attach a primary macro and optional changeup before sending either answer to the Weekly Gameplan.

8. Create the ChatGPT handoff

Add public YouTube or Twitch film links, optional transcript and timestamp notes, then download or copy the generated packet for ChatGPT. Paste the returned written plan back into the site to retain it.

9. Build a weekly gameplan

Select an opponent and situation, then add the current play, a saved macro, a tested scout-lab matchup, or a tendency-board answer. Reorder calls, reload them into the field, and print a clean call sheet.

Storage and sharing

  • Saved data stays in Chrome on the current device.
  • Use Export Backup before clearing browser data or moving computers.
  • Send the HTML file to another user; they can open it directly in Chrome.
  • Use Import Backup to transfer macros, play maps, My Playbook, the weekly gameplan, team navigator preferences, the opponent scout report, the tendency board, and the ChatGPT handoff.
  • Reset Entire App deletes only this tool's locally saved macros, maps, favorites, and weekly gameplan.

Assignment accuracy

The menu is conservatively filtered by defender role. Exact hot-route availability can still vary by formation and package, so verify questionable options in CFB 27 before marking a play map verified.
